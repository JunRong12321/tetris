# Online Multiplayer Tetris — Specification Package

This package contains the approved-before-coding documents for the project.

## Documents

- `docs/PRD.md` — Product requirements, MVP scope, gameplay requirements, acceptance criteria.
- `docs/DESIGN_SYSTEM.md` — UI/UX rules, visual language, tokens, components, responsive/accessibility requirements.
- `docs/ARCHITECTURE.md` — Technical architecture, multiplayer authority model, protocol, testing, deployment, scaling.
- `docs/AGENT_INSTRUCTIONS.md` — Rules for AI coding agents and vibe-coding workflow.

## Review Process

Review these documents before implementation begins.

Recommended approval order:

1. PRD
2. Design System
3. Architecture
4. Agent Instructions

After approval, implementation should start with repository foundation and the deterministic game engine before multiplayer UI.
